# C Bitwise Operators

A beginner-friendly C programming project focused on **Bitwise Operators and Bit Manipulation**.

## 🔹 Bitwise Operators

* `&` — Bitwise AND — Check or clear bits
* `|` — Bitwise OR — Set bits
* `^` — Bitwise XOR — Toggle bits
* `~` — Bitwise NOT — Invert all bits
* `<<` — Left Shift — Shift bits to the left
* `>>` — Right Shift — Shift bits to the right
         
## 🔧 Bit Manipulation

Common operations:

```c
// Set bit
s = s | (1 << n);

// Clear bit
s = s & ~(1 << n);

// Check bit
s & (1 << n);

// Toggle bit
s = s ^ (1 << n);
```
