# C-Bitwise-Operations

A beginner-friendly C programming practice project focused on **Bitwise Operators and Bit Manipulation**.

## 📌 Topics Covered

- Bitwise AND &
- Bitwise OR |
- Bitwise XOR ^
- Bitwise NOT ~
- Left Shift <<
- Right Shift >>
- Setting a bit
- Clearing a bit
- Checking a bit
- Toggling a bit
